# Program-6-Coding-with-Gen-AI
# Robot Functionality Checker

## Problem
I want to make a Java program to check if a robot works. The program will check the battery, motors, camera, sensors, and connection. It will show which parts work and which parts do not work. I will use OOP and a Queue to check each part one by one.
## Reflection
During this process, I learned how to tell AI what I specifically need and how to give specific instructions. I also learned how to use GitHub and Git commits to record my programming process with AI, and how to use a Queue, OOP, and a HashMap in a Java program.
There are many advantages to using AI. The first one is saving time. AI can write a program from beginning to end with just one click. I feel that AI is a very useful and time-saving tool. It is really amazing that I can turn my ideas into a real program. The program actually works and follows my ideas. Using AI also helped me understand data structures and the program, and fix mistakes during the programming process.
However, there are also some disadvantages to using AI. The code generated by AI does not always match my ideas. Sometimes AI makes mistakes, and I have to check the code, report the mistakes to AI, and run the program again. Overusing AI might also decrease my ability to program independently.
AI is a powerful tool, and we can use it, but we cannot let it replace our own thinking. Programmers still need to know how to program so that they can judge whether the code generated by AI is correct or not.
